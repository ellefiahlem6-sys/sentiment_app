# sentiment_app
# 📊 Customer Sentiment Analyzer

## 📌 Project Overview
An AI-powered web application that analyzes customer reviews and classifies them as POSITIVE or NEGATIVE. Built with Streamlit and Hugging Face Transformers.

## 🎯 Business Value
- Automates the analysis of thousands of customer reviews.
- Provides instant insights into customer satisfaction.
- Helps businesses identify problems and improve products quickly.

## 🛠️ Tech Stack
- Python
- Streamlit (Web App)
- Hugging Face Transformers (NLP Model)
- PyTorch (Backend)
